# PyTasks Premium

A modern, offline-first, premium task management application built with **Python** and **PySide6**.

## Features
- **Frameless, Rounded UI:** A sleek, dark-mode glassmorphic interface with smooth animations.
- **SQLite Backend:** Fast, local, and reliable storage. No accounts, no cloud.
- **Kanban Board:** Drag-and-drop task management with real-time SQLite syncing.
- **Analytics:** Live custom-drawn charts of your productivity.
- **Multi-View:** Inbox, My Day, Upcoming, Projects, Tags, and Calendar.
- **Custom Themes:** Switch between Premium Dark and Light modes instantly.

## Installation
1. Install the required package: `pip install -r requirements.txt`
2. Run the application: `python main.py`

## Data Location
Your tasks are safely stored locally at: `%APPDATA%\PyTasks\pytasks.db`
